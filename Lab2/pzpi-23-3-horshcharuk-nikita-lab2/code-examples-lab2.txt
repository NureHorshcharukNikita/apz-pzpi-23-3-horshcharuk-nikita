Назва інструменту та версія:
ChatGPT (OpenAI), модель GPT-5.3.

Мета використання:

Інструмент використано для прискорення процесу розробки мобільного застосунку Elevate та формування окремих частин коду і архітектурних рішень.

Штучний інтелект застосовувався для:

генерації шаблонів коду для Flutter (екрани, віджети, viewmodel);
побудови структури проєкту відповідно до Clean Architecture;
написання HTTP-запитів із використанням Dio;
реалізації базових провайдерів стану за допомогою Riverpod;
створення моделей даних (DTO) та їх серіалізації;
формування прикладів взаємодії з REST API;
генерації початкових варіантів навігації через go_router;
швидкого прототипування окремих функціональних компонентів (auth, profile, leaderboard, activity).

Використання штучного інтелекту дозволило значно скоротити час на написання типового коду, уникнути рутинних помилок та зосередитися на архітектурі й логіці застосунку.

Внесок автора:

Автор сформулював запити до штучного інтелекту відповідно до вимог мобільного застосунку Elevate та обраної архітектури. Згенерований код не використовувався безпосередньо у фінальній версії без перевірки. Усі результати були проаналізовані, адаптовані до структури проєкту та інтегровані вручну.

Автор виконав:

перевірку коректності згенерованого коду;
адаптацію коду під архітектуру застосунку (Clean Architecture + MVVM);
інтеграцію з реальним REST API серверної частини;
оптимізацію взаємодії між шарами;
рефакторинг та приведення коду до єдиного стилю;
виправлення помилок і неточностей, що виникали у згенерованих фрагментах.

Таким чином, штучний інтелект використовувався як допоміжний інструмент, а остаточна реалізація була виконана автором.
